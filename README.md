## Таблица для Google Sheets

Файл для вставки: `catalog-simple.tsv`.

В таблице шесть колонок:

```text
Название
Категория
Статус
Описание
Цена
Цена со скидкой
```

В колонке `Описание` можно начинать текст с `Состав:`. Если `Цена со скидкой` пустая, сайт показывает обычную цену. Если `Цена со скидкой` заполнена, обычная цена будет зачеркнута, а рядом появится цена со скидкой.

Допустимые статусы:

```text
есть
под заказ
нет
```

Категории можно писать так:

```text
Горячее
Полуфабрикаты
Мясное
Десерты
Салаты
Дополнительно
```
